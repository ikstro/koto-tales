# Льошині бажання — the wish log

One short file per idea Льоша has for the game: `wishes/<YYYY-MM-DD>-<slug>.md`. The `/wish` skill
writes it; the owner's backlog lives here. Children's words only — never photos, surnames or places.

```md
# <short name>
- date: 2026-10-30
- said: «<Льоша's words, verbatim, in his language>»
- kinds: monster | item | artifact | building | companion | tale (one or more)
- status: idea | in game | needs engine
- notes: how it maps onto CONTENT.md; what was asked of the owner and their answers
- ids: <card ids once made>
```

- `idea` — logged, not built yet.
- `in game` — its cards are in, voiced, and `npm run check` is green.
- `needs engine` — a part fits no word in CONTENT.md; the nearest fit and the engine verb it would need
  are in `notes`, waiting for the owner's yes.

Borrowed characters (a cartoon, an internet monster) become the game's own toy: own name, own look,
no brand.
