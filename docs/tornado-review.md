# Два торнадо — рабочая версия на просмотр

## Как попробовать

Тестовая сцена: http://127.0.0.1:5299/?autostart=1&fresh=1&x=40&z=30&tornado=both&give=wind_whistle

Сервер запускается из корня проекта: `npm run dev -- --host 127.0.0.1 --port 5299 --strictPort`.
Это отдельный локальный адрес; сохранение опубликованной игры не затрагивается.

1. Огненный вихрь предупреждает перед погоней. От него можно отбежать или провести рядом монстров.
2. В наборе есть голубой свисток. Он многоразовый: вызови синий вихрь, прикоснись к нему, управляй обычным джойстиком. Прыжок просит безопасную высадку.
3. В начале каждого нового игрового дня первая поездка даёт пирожок. Повторный вызов и перезапуск не повторяют подарок.
4. Для просмотра первой сказки добавь `&tale=wind_friend`. В обычной игре она идёт после Сірка: собрать три мушли, поставить колонку рядом и включить музыку, получить свисток. Это новая сказка Пупси по идее торнадо, а не дословная история Льоші.

Картинки: `design-lab/tornado/game-riding.png`, `design-lab/tornado/game-both.png`, `design-lab/new/wind_whistle.png`.

## Проверено

- 860 тестов и TypeScript, в том числе с `STRICT_VOICE=1`; production-сборка PWA.
- В настоящем браузере: касание, движение всей четвёрки, прыжок, безопасная высадка, многоразовый инструмент, дневной подарок, урон и обычная награда за победу огнём, пауза.
- В стресс-сцене работают оба вихря, дождь и восемь монстров. Два вихря добавляют 4 вызова отрисовки и 1 208 треугольников на качестве 0; переключение не создаёт новые шейдеры, текстуры или геометрии. Графические ресурсы выделены один раз.
- Штатный маршрут с настоящим стартом, деревнями, замками, порталом и картой: 0 зависаний после старта. В исходном Git HEAD — тоже 0. В обеих версиях по 11 поздних подгрузок старых шейдеров; новые шейдеры самих вихрей подготовлены заранее.
- Проверены размеры HUD: 1280×800, 1024×600, 844×390, 390×844. Для игры на планшете ещё требуется проверка на самом устройстве.
- Размер кода относительно исходного Git HEAD: +5 815 байт gzip при одинаковом способе сжатия. Отдельная картинка обновления — 36 284 байта; 12 новых MP3 — 485 424 байта, около 81 секунды звука суммарно. У игры остаётся один обычный голосовой канал.
- Все 12 MP3 проверены через ffprobe и декодированы браузером: аудио не пустое, файлы входят в индекс. Рассказчик и Пупся запускаются через настоящий игровой аудиоконтроллер. Генератор создал 12 записей, сохранил 1006 прежних без изменений, ошибок нет.

Замеры: `design-lab/tornado/game-results.json`, `size-results.json`, `baseline-perf.txt`.
